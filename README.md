# Personal Portfolio Website

This is a personal portfolio website built using **HTML**, **CSS**, and **JavaScript**. The website showcases personal information such as education, skills, projects, and services. The design is fully responsive and works across various screen sizes.

## Features
- **Smooth Scrolling**: For a seamless browsing experience.
- **Education Section**: Highlights your academic background.
- **Skills Section**: Lists technical and soft skills.
- **Projects Section**: Showcases the projects worked on.
- **Services Section**: Lists the services offered (e.g., web development, consulting).

## Technologies Used

- **HTML**: Markup language used to structure the content.
- **CSS**: Used for layout, styling, and responsive design.
- **JavaScript**: Adds interactivity and dynamic content.
